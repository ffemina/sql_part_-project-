# GYM_MANAGEMENT_SYSTEM
This project focuses on designing a relational database for a Gym Management System using MySQL. It organizes and manages essential gym operations, including member registration, trainer information, gym classes, membership plans, and payment details.  
Project Overview

This project focuses on designing an Enhanced Entity-Relationship (EER) Diagram for a Gym Management System using MySQL Workbench. It represents the database structure and relationships required to manage gym operations efficiently.

🎯 Objectives

Design a structured database for a Gym Management System.

Identify entities and their attributes.

Establish relationships between entities.

Understand Primary Keys and Foreign Keys.

Create an organized database model.

🛠️ Tools Used

MySQL Workbench

EER Diagram

Database Management System (DBMS)

Entity-Relationship Modeling
